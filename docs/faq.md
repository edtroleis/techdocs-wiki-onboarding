# FAQ

??? question "Não encontro meu serviço no Backstage"
    Verifique se o repo tem `catalog-info.yaml` e se ele foi registrado
    (Create → Register Existing Component).

??? question "A aba Docs mostra 'documentação não encontrada'"
    As docs são geradas pelo CI e publicadas fora do Backstage. Confirme se o pipeline
    rodou com sucesso depois do último merge.

??? question "Posso usar outra linguagem fora do golden path?"
    Pode, com um ADR justificando. Veja o
    [golden path](http://localhost:3000/docs/default/component/wiki-golden-path).

??? question "Onde ficam os padrões de código?"
    Na [Wiki de Engenharia](http://localhost:3000/docs/default/component/wiki-engineering).
